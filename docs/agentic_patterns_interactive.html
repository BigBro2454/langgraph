Tree-of-Thought (ToT)
Chapter 2.4
Models reasoning as search through a tree of intermediate thoughts. Proposes K branches, scores candidates with an evaluation rubric, and prunes weak paths.
Branch (K=3) ──► Evaluator (Score 1-10) ▲ │ │ Prune (Beam=2) │ │ └── [Depth < Max?] ◄────┤ └── [Depth reached] ──► Synthesize
Benchmark Lift 74% vs 4% on Game of 24
Complexity High (Search-based)
Primary Risk Token cost K × depth
Mitigation Shallow beam search (depth 2–3)

3-Layer Defense & Constitutional AI
Chapters 7.3 & 8.1
Zero-trust architectural guardrails:
• Layer 1 (Input Guard): Pre-execution classifier detects prompt injection, jailbreaks, and out-of-scope requests.
• Layer 2 (Reasoning Guard): Enforces strict tool calling boundaries, budget caps, and turn limiters.
• Layer 3 (Constitutional Auditor): Audits candidate outputs against explicit safety principles (Factuality, Privacy, Tone) and executes automated remediation loops before final delivery.
User Input ──► [Layer 1 Input Guard] │ [Injection / Threat?] ├── YES ──► REJECT IMMEDIATELY (Red Gate) └── NO ──► Core Reasoner │ ▼ [Layer 3 Constitutional Auditor] │ [Violates Principles?] ├── YES ──► Auto-Remediator Rewrite ──┐ │ ▲ │ │ └────────────────┘ └── NO ──► Final Delivery
Escape Rate < 0.1% Policy Violations
Injection Defense 100% Blocked at Layer 1
Latency Overhead +15% to +20%
Constitutional Loop Max 2 Revisions
