Translating complex distributed agent systems into actionable product frameworks.

First Principle: An Agent is a Finite State Machine with Tools

Traditional microservices have deterministic branching (if/else). LLM chatbots have open-ended conversations. An Agent merges both: predictable state checkpoints combined with non-deterministic LLM reasoning confined strictly to typed tool executions.

Engineering Concept PM Mental Model Product Decision / Impact
State & Reducers The Living User Session Dictates what data is retained between conversational turns and what is ephemeral.
Checkpointer The Durable Flight Recorder Guarantees state survives server restarts, crashes, and enables state rewind (Time Travel).
dynamic interrupt() The Executive Approval Gate Mandatory for high-blast-radius operations (fund transfers, data deletion, code deployment).
Supervisor Pattern The Product Team Manager Splits monolithic system prompts into specialized domain micro-agents (Researcher, Writer, Reviewer).
Middleware Quality & Cost Guardrails Intercepts prompts before the LLM to prune bloat, redact PII, or enforce token budgets.

Agent 1: Hello World (ReAct Pattern)

Foundational cyclic reasoning loop executing typed arithmetic operations with automatic tool routing.

● agents/hello_world/agent.py
StateGraph + ToolNode
class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], add_messages]

tools = [add, subtract, multiply, divide]
tool_node = ToolNode(tools)
model = get_model().bind_tools(tools)

def call_model(state: AgentState):
    return {"messages": [model.invoke(state["messages"])]}

workflow = StateGraph(AgentState)
workflow.add_node("agent", call_model)
workflow.add_node("tools", tool_node)

workflow.add_edge(START, "agent")
workflow.add_conditional_edges("agent", tools_condition)
workflow.add_edge("tools", "agent")
graph = workflow.compile()

add_messages: LangGraph reducer that merges AIMessages and ToolMessages sequentially without loss.

ToolNode: Built-in prebuilt node that unpacks tool calls from the LLM response, executes them, and yields ToolMessage results.

tools_condition: Conditional edge router that checks if the last message contains tool requests. If yes -> tools; else -> END.

Agent 3: Human-in-the-Loop (HITL) Governance

Dynamic runtime pause and resumption mechanism using `interrupt()` and `Command(resume=...)`.

● agents/hitl_agent/agent.py
Dynamic interrupt() & Command
def human_gate_node(state: HITLState):
    pending = state.get("action_pending")
    # Pauses execution and surfaces payload to client
    approval_decision = interrupt({
        "question": f"Approval needed: {pending}",
        "options": ["APPROVED", "REJECTED"],
    })
    return {"approval_status": str(approval_decision).upper()}

# To Resume:
resumed = graph.invoke(
    Command(resume="APPROVED"),
    config={"configurable": {"thread_id": "session-1"}}
)

Zero Polling: When interrupt() is triggered, the thread serializes into durable storage and execution immediately halts.

Command(resume=...): Allows external human operators (via Slack, Web UI, or mobile approval) to inject authorization payloads to resume exactly where left off.

Agent 5: Deep Agent Pattern & Context Engineering

Long-running harness with middleware context pruning and AGENTS.md / SKILL.md file conventions.

📄

AGENTS.md vs. SKILL.md

AGENTS.md: The global product specification and operational rules loaded at startup.

SKILL.md: Procedural capabilities loaded strictly on-demand using Progressive Disclosure to prevent context window bloat.

✂️

Context Engineering Middleware

Automatically analyzes token budgets, summarizes historical turns, and prunes low-signal messages before prompting the model, slashing API costs by up to 60% in long sessions.
