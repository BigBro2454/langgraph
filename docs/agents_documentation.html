GRAPH Foundational Cyclic State Machine agents/hello_world/agent.py 
class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], add_messages]

tools = [add, subtract, multiply, divide]
tool_node = ToolNode(tools)
model = get_model().bind_tools(tools)

def call_model(state: AgentState):
    return {"messages": [model.invoke(state["messages"])]}

workflow = StateGraph(AgentState)
workflow.add_node("agent", call_model)
workflow.add_node("tools", tool_node)
workflow.add_edge(START, "agent")
workflow.add_conditional_edges("agent", tools_condition)
workflow.add_edge("tools", "agent")
graph = workflow.compile()
add_messages Reducer: LangGraph reducer ensuring returning a list of new messages appends them rather than overwriting.
ToolNode: Built-in prebuilt node that unpacks tool calls from the LLM response, executes them, and yields ToolMessage results.
tools_condition: Conditional edge router inspecting the last message. If tool_calls present -> tools; else -> END.

hitl_agent · Human-in-the-Loop Governance

Pauses execution at predefined approval gates using native interrupt() and resumes with Command(resume=...).

Dynamic interrupt() Command(resume) Blast Radius Protection
HITL GATE Dynamic Interrupt & Resumption agents/hitl_agent/agent.py 
def human_approval_node(state: HITLState):
    action = state["action_pending"]
    # Pauses execution and surfaces payload to client
    approval = interrupt({
        "question": f"Authorize production action: {action}?",
        "options": ["APPROVED", "REJECTED"]
    })
    return {"approval_status": str(approval).upper()}

# To Resume:
resumed = graph.invoke(
    Command(resume="APPROVED"),
    config={"configurable": {"thread_id": "session-1"}}
)
Zero Polling: When interrupt() is reached, LangGraph serializes the state to disk and halts execution without burning CPU cycles.
Command(resume=...): Allows Slack bots, mobile push notifications, or web dashboards to pass human authorization back into the thread.

When to Use vs Not Use

Use for straightforward linear tasks (<8 steps). Avoid for complex 10+ step workflows where errors compound exponentially.

Verbal Memory vs. Weight Fine-Tuning

Zero Fine-Tuning Cost

Reflexion mimics human trial-and-error learning by storing concise post-mortem reflections in prompt context, achieving fine-tuning level accuracy without GPU retraining.

Requirement: Reliable Evaluator

Reflexion requires an unambiguous pass/fail evaluator (compiler, unit test, or strict JSON rubric) to prevent reinforcing bad solutions.

High-Stakes Decision Spaces

Exploitation vs Exploration

The UCB1 formula guarantees that the agent doesn't prematurely settle on the first reasonable plan, actively probing unvisited paths with high upside potential.

Token Economics

Generates high token volume (5-15x linear reasoning). Reserve strictly for high-stakes code generation, security audits, or mission-critical architecture.
